# JobPilotAI desktop app

Downloads for the JobPilotAI interview copilot. Sign up and get started at **https://jobpilotai-app.vercel.app**.

| Platform | Download |
| --- | --- |
| Windows 10 (2004+) / 11 | [JobPilotAI-Setup.exe](https://github.com/swapnil2474/jobpilot-ai-releases/releases/latest/download/JobPilotAI-Setup.exe) |
| macOS (Apple Silicon, M1 or newer) | [JobPilotAI.dmg](https://github.com/swapnil2474/jobpilot-ai-releases/releases/latest/download/JobPilotAI.dmg) |

**First launch**
- Windows: if "Windows protected your PC" appears, click **More info → Run anyway**.
- macOS: right-click the app and choose **Open**.

Need help? See [How to use JobPilotAI](https://jobpilotai-app.vercel.app/how-to-use).

This repository only hosts installers. The source code is private.
